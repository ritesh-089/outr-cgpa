# OUTR CGPA Calculator — Final

## Change the logo yourself
Open:
`assets/outr-logo.svg`

Replace that file with your own logo and keep the filename `outr-logo.svg`.
Then commit the change in GitHub. Refresh the website.

If you use a PNG/JPG instead, change this line in `index.html`:
`src="assets/outr-logo.svg"`
to your filename, e.g.:
`src="assets/outr-logo.png"`
